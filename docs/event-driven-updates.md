# Этап 2.2 — Event-Driven Updates

Интерфейс обновляется по изменению значения или действию пользователя. Частоты
получения данных и кадров анимации остаются независимыми, как в этапе 2.1.

| Виджет | Событие для интерфейса | Резервный опрос |
| --- | --- | --- |
| Music | `OnChangeAction` заголовка, исполнителя, пути обложки и состояния; анимация через `ActionTimer` | 1 с для содержимого обложки, которое может измениться по тому же пути; 100 мс для состояния и наведения |
| Volume | Существующие `OnChangeAction` источников запускают анимации только при смене уровня | Системный уровень и приложения опрашиваются существующими плагинами |
| Brightness и вертикальный Volume | Действия мыши переключают опрос на 17 мс; анимация использует `ActionTimer` | Примерно 100 мс в простое для внешних изменений системы |
| Monitor | Изменение системного показателя запускает короткую анимацию; Bluetooth watcher отслеживает события устройств | 1 с для CPU, RAM, диска, сети и поколения снимка Bluetooth; батарея и пропускная способность — реже |
| Weather | Ответ WebParser и смена часа публикуются только при изменении отображаемых значений | Существующие 900 с для прогноза и 1 с для таймеров повтора после ошибки |
| Clock | Изменение времени | 100 мс для плавной секундной стрелки, с существующим режимом экономии |
| Timer | Действия start/pause/stop и смена отображаемых часов, минут, секунд | 100 мс во время обратного отсчёта для плавного кольца |
| Calendar | Смена даты запускает существующее обновление календаря | Проверка даты каждые 5 с |
| Notes и Reminders | Ввод и правки обновляют нужные элементы непосредственно | Фоновое обновление отключено |

Новые процессы и зависимости для работающего Rainmeter не добавлены. Нативные
плагины Volume и системных показателей не предоставляют здесь событий изменения;
их интервалы оставлены как fallback. Проверка аппаратных сценариев (изменение
яркости, громкости и Bluetooth вне Rainmeter) требует запуска на рабочем столе.

Автоматические проверки: `python -m unittest test_event_updates.EventUpdateTests`
и `python -m unittest test_lua.LuaTests.test_all_scripts_compile_as_lua51`
при `PYTHONPATH`, включающем `tests` и зависимости из `tests/requirements.txt`.
